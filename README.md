# kursa4 — платформа объявлений о недвижимости

Курсовой проект: веб-сервис для размещения и поиска объявлений о продаже
и аренде недвижимости (квартиры, дома, коммерческая недвижимость).

## Стек

| Часть    | Технологии                                                    |
| -------- | ------------------------------------------------------------- |
| Бэкенд   | Python 3.12+, Django 6.1, Django REST Framework, SQLite       |
| Фронтенд | React 18, Redux Toolkit (RTK Query), React Router 7, CRA      |

## Структура

```
backend/
  requirements.txt        зависимости Python
  RealEstate/
    manage.py
    RealEstate/           настройки проекта (settings.py, urls.py)
    application/          модели, сериализаторы, представления, тесты
frontend/
  realestate/
    src/components/       React-компоненты страниц
    src/features/api/     RTK Query (apiSlice.js) — все запросы к API
    src/styles/           CSS-модули
```

## Запуск

Нужны **Python 3.12+** и **Node.js 18+**.

### 1. Бэкенд (http://127.0.0.1:8000)

```bash
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate
# Linux / macOS
source .venv/bin/activate

pip install -r requirements.txt

cd RealEstate
python manage.py migrate
python manage.py createsuperuser   # аккаунт для /admin/
python manage.py seed_demo         # 30 демо-объявлений с фото (нужен интернет)
python manage.py runserver
```

> Запускайте сервер именно из `.venv`: проект рассчитан на Django 6.1 из
> `requirements.txt`. С другой версией Django (например, установленной в
> системный Python) часть настроек ведёт себя иначе.

Письма (ссылка для сброса пароля) не отправляются на почту, а печатаются
в консоли, где запущен `runserver`.

### 2. Фронтенд (http://localhost:3000)

В отдельном терминале:

```bash
cd frontend/realestate
npm install
npm start
```

Если бэкенд работает не на `http://127.0.0.1:8000`, скопируйте
`.env.example` в `.env` и укажите адрес в `REACT_APP_API_URL`.

### Демо-данные

`python manage.py seed_demo` создаёт 30 объявлений (10 квартир, 10 домов,
10 коммерческих помещений) в 14 городах Казахстана от пяти демо-продавцов.
Фотографии — бесплатные изображения с [Unsplash](https://unsplash.com/license);
при первом запуске они скачиваются в `media/demo_cache/` (~15 МБ).

Повторный запуск пересоздаёт демо-объявления, не трогая остальные данные.
`python manage.py seed_demo --clear` удаляет демо-данные.

Под демо-продавцами можно войти — у всех общий пароль `demo12345`
(по 6 объявлений у каждого):

| Логин          | Имя на сайте      |
| -------------- | ----------------- |
| `demo_aigerim` | Айгерим Сапарова  |
| `demo_daniyar` | Данияр Ахметов    |
| `demo_elena`   | Елена Ковальчук   |
| `demo_nurlan`  | Нурлан Бекенов    |
| `demo_realty`  | Агентство «Ключ»  |

Пароль хранится в репозитории открытым текстом, поэтому годится только для
демо-аккаунтов. Если сайт окажется в открытом доступе, удалите демо-данные
(`seed_demo --clear`).

## Переменные окружения бэкенда

Для локальной разработки ничего задавать не нужно.

| Переменная             | По умолчанию          | Назначение                                     |
| ---------------------- | --------------------- | ---------------------------------------------- |
| `DJANGO_DEBUG`         | `True`                | Режим отладки                                  |
| `DJANGO_SECRET_KEY`    | ключ для разработки   | Обязателен, если `DJANGO_DEBUG=False`          |
| `DJANGO_ALLOWED_HOSTS` | `localhost,127.0.0.1` | Список хостов через запятую                    |
| `FRONTEND_URL`         | `http://localhost:3000` | Адрес фронтенда для ссылок в письмах         |

## API

Базовый адрес: `http://127.0.0.1:8000/api/`

### Авторизация

Вход и регистрация возвращают токен:
`{ "token": "…", "user": { … } }`. Его нужно передавать в заголовке
`Authorization: Token <token>`.

Читать объявления и профили продавцов могут все. Создавать объявления и
работать с избранным — только авторизованные пользователи. Изменять и удалять
объявление и его фото — только владелец (иначе `403`).

| Метод                  | Адрес                              | Доступ        | Описание                                   |
| ---------------------- | ---------------------------------- | ------------- | ------------------------------------------ |
| `GET`                  | `/properties/`                     | все           | Список активных объявлений (с пагинацией)  |
| `POST`                 | `/properties/`                     | авторизованные | Создание; владелец — текущий пользователь |
| `GET`                  | `/properties/<id>/`                | все           | Объявление                                 |
| `PUT`, `DELETE`        | `/properties/<id>/`                | владелец      | Изменение / удаление                       |
| `POST`                 | `/properties/<id>/photos/`         | владелец      | Загрузка фото (multipart, `image`; до 10 штук, до 5 МБ) |
| `POST`                 | `/properties/<id>/photos/order/`   | владелец      | Порядок фото: `{ "ids": [...] }`, первое — обложка |
| `DELETE`               | `/photos/<id>/`                    | владелец      | Удаление фото (вместе с файлами)           |
| `GET`, `POST`          | `/favorites/`                      | авторизованные | Своё избранное / добавить `{ "property": id }` |
| `DELETE`               | `/favorites/<id>/`                 | авторизованные | Удалить из своего избранного              |
| `GET`                  | `/users/<id>/`                     | все           | Карточка продавца (имя и телефон, без email) |
| `GET`, `PUT`           | `/users/me/`                       | авторизованные | Свой профиль                              |
| `POST`                 | `/register/`, `/login/`            | все           | Регистрация / вход, возвращают токен       |
| `POST`                 | `/logout/`                         | авторизованные | Выход: токен перестаёт действовать        |
| `POST`                 | `/password-reset/`                 | все           | Ссылка для сброса пароля `{ "email": … }` |
| `POST`                 | `/password-reset/confirm/`         | все           | Новый пароль `{ "uid", "token", "password" }` |

### Параметры `GET /properties/`

| Параметр        | Пример                     | Описание                                  |
| --------------- | -------------------------- | ----------------------------------------- |
| `page`          | `2`                        | Номер страницы                            |
| `page_size`     | `12`                       | Размер страницы (по умолчанию 12, макс. 50) |
| `owner`         | `3`                        | Объявления пользователя; владельцу видны и проданные/архивные |
| `property_type` | `apartment`, `house`, `commercial` | Тип недвижимости                  |
| `deal_type`     | `sale`, `rent`             | Тип сделки                                |
| `search`        | `караганда`                | Поиск по городу и адресу без учёта регистра |
| `price_min`, `price_max` | `5000000`         | Цена от / до                              |
| `area_min`, `area_max`   | `40`              | Площадь от / до, м²                       |
| `rooms`         | `1,2` или `4`              | Число комнат; `4` означает «4 и больше»  |
| `ordering`      | `newest`, `priceAsc`, `priceDesc` | Сортировка                         |

Ответ: `{ "count": 30, "next": "...", "previous": null, "results": [...] }`.
